# بوت تيليجرام المطور - النسخة الكاملة

## هيكل المشروع

```
bot_upgraded/
├── bot.py                  # الملف الرئيسي
├── bot_helpers.py          # دوال مساعدة مشتركة
├── requirements.txt
├── .env                    # متغيرات البيئة (أنشئه من .env.example)
├── bot_data.db             # قاعدة البيانات (تُنشأ تلقائياً)
├── downloads/              # مجلد التحميلات المؤقتة
└── modules/
    ├── database.py         # قاعدة البيانات SQLite
    ├── admin_panel.py      # لوحة الإدارة الكاملة
    ├── forced_sub.py       # الاشتراك الإجباري مع الأهداف
    └── queue_manager.py    # Queue + كاش ذكي
```

## التثبيت

```bash
pip install -r requirements.txt
cp .env.example .env
# عدّل .env وضع BOT_TOKEN و ADMIN_ID
python bot.py
```

## الميزات

### لوحة الإدارة (بالأزرار فقط)
- 📊 الإحصائيات الكاملة
- 📢 إدارة قنوات الاشتراك الإجباري مع أهداف المشتركين وشريط تقدم
- 🎛 إدارة أزرار واجهة المستخدم (إضافة/حذف/إخفاء/ترتيب/تثبيت)
- ✉️ تعديل جميع رسائل البوت
- 👮 إدارة الأدمن (كامل/محدود)
- 📣 إذاعة احترافية (للجميع/VIP/النشطين/اليوم) مع متابعة مباشرة
- 🌐 تفعيل/تعطيل المنصات بضغطة زر
- 🏪 متجر منتجات
- ⚡ مراقبة الأداء (CPU/RAM) وتحكم في الكاش والـ Queue

### التحميل
- ✅ يحافظ على جميع وظائف التحميل الأصلية
- 🗂 كاش ذكي (نفس الرابط = تحميل فوري)
- 📋 Queue ذكي مع عرض الترتيب
- ⚙️ جودة التحميل قابلة للتغيير من لوحة الإدارة

### الإذاعة
- دفعات من 30-50 مستخدم
- معالجة FloodWait تلقائياً
- تنظيف قاعدة البيانات من الحسابات المحظورة
- أزرار إيقاف مؤقت / استئناف / إلغاء
